# 수동 테스트 체크리스트

권한·단축키·Spaces 동작은 자동으로 검증할 수 없다. 변경한 영역의 항목을 골라 사용자에게 번호 목록으로 제시하고 결과를 받는다.
SPEC §7을 바탕으로 개발 중 발견한 항목을 더했다. 새 버그를 고치면 재발 확인 항목을 여기에 추가한다.

자동 점검(먼저 실행): `swift scripts/smoke.swift` — 패널 열림(<100ms) · Sticky 유지 · Esc 닫힘

## Spaces / 메뉴바
- [ ] 데스크탑 전환 시 메뉴바 이름이 1초 이내 갱신
- [ ] 데스크탑 추가/삭제/순서 변경 후 메뉴 목록이 올바름 (메뉴를 열 때마다 재조회)
- [ ] 전체화면 앱 Space는 목록에 없음, 전체화면 위에서는 메뉴바에 "전체화면"

## 이동 시 이름 표시 (#13)
- [ ] 트랙패드 스와이프 · Ctrl+→ · 스위처 어느 방법으로 옮겨도 가운데에 `N · 이름`이 잠깐 떴다 사라짐 (이름 없으면 `데스크탑 N`)
- [ ] 표시 중에도 클릭·타이핑이 아래 앱에 그대로 전달됨
- [ ] 빠르게 연속 이동 → 마지막 데스크탑 이름만 남음 / 전체화면 앱으로 이동 시 표시 없음
- [ ] 설정 → 일반: 끄기, 표시 시간(짧게/보통/길게), 위치(가운데/위쪽) 즉시 반영

## 전환
- [ ] 메뉴에서 데스크탑 선택 → 이동
- [ ] "데스크탑 N으로 전환" 단축키가 꺼진 데스크탑 → Ctrl+←/→ 경로로 한 칸씩 이동해 도착
- [ ] 스위처로 이동한 **직후** Option+E → "삑" 없이 패널 뜸 (합성 Ctrl 잔류 회귀 방지)
- [ ] (#8) 단축키가 꺼진 데스크탑으로 스위처 이동 → 패널이 먼저 사라진 뒤 슬라이드 (지나가는 화면에 패널 없음)

## 스위처
- [ ] Option+E 짧게 → 패널 유지(Sticky), 첫 선택이 설정값(기본: 현재 데스크탑)
- [ ] Sticky에서 ↑/↓, E, Shift+E로 선택 이동 / Enter로 전환 / Esc·바깥 클릭으로 닫기
- [ ] Sticky에서 숫자키 3 → 데스크탑 3으로 즉시 전환
- [ ] Option 누른 채 E 두 번 이상 → Option 떼면 선택 데스크탑으로 전환 / Shift+E는 역방향
- [ ] E를 꾹 누르고 있어도 한 칸만 이동 (autorepeat 무시)
- [ ] 텍스트 입력 중 Option+E → ´ 문자가 입력되지 않음
- [ ] 전체화면 앱 위에서도 패널이 뜨고, 패널 때문에 Space가 바뀌지 않음
- [ ] 패널에서 R 또는 더블클릭 → 이름 편집 → Enter → 메뉴바에 즉시 반영
- [ ] (#7) R → Esc → 편집만 취소, 창 유지 · ↑↓/Enter 계속 동작
- [ ] (#7) R → 수정 → Enter → 저장되고 창 유지
- [ ] (#7) 편집 후 Esc로 닫고 Option+E → 클릭 없이 바로 다시 뜸 · 원래 앱에 타이핑 정상

## 이름
- [ ] 이름 붙이고 앱 재시작 → 유지 / 재부팅 → 유지
- [ ] 이름 붙인 데스크탑을 Mission Control에서 다른 자리로 옮김 → 이름이 따라감(번호만 바뀜)
- [ ] 설정 → 데스크탑 탭에서 편집, "사용하지 않는 이름 정리"

## 설정 / 권한
- [ ] 권한 없는 상태로 첫 실행 → 온보딩 표시, 권한 부여 후 재시작 없이 동작
- [ ] 재빌드(빌드 번호 변경) 후에도 손쉬운 사용 권한 유지
- [ ] 단축키를 Ctrl+Option+Space로 녹화 → 즉시 동작 → 기본값 복원
- [ ] 첫 선택 "직전 데스크탑"으로 변경 → 떠나온 데스크탑이 선택됨
- [ ] 로그인 시 자동 실행 on → 재부팅/재로그인 후 메뉴바에 앱
- [ ] 슬립/깨우기 후에도 단축키 동작 (이벤트 탭 재활성화)
- [ ] (#10) 앱 재설치 직후 · 데스크탑 연속 전환 중에도 Option+E가 ´ 없이 뜸. 이상하면 `log show --last 10m --predicate 'subsystem == "io.github.unh6unh6.SpaceSwitcher"'`에 slow tap / disabled 기록 확인
